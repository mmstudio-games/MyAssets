# 资产生成方向决策指南

> 面向**使用者**：你的游戏需要某个资产时，该用哪种方式生成？本指南给出三分法 + 决策树，帮你在 **技术美术（TA）**、**MyAssets**、**AI 文生图** 之间选对方向。
> 原则一句话：**动态效果归引擎，确定性格子归 MyAssets，艺术细节归文生图。**

## 三分法总览

| 生成方式 | 适合的资产 | 优势 | 劣势 |
|---|---|---|---|
| **技术美术（TA）/ 引擎** | 粒子、shader 后处理、物理模拟 | 实时、可调参、不占包体 | 需要 TA 技能，运行时开销 |
| **MyAssets（HTML/CSS）** | 静态 UI、程序化贴图、UI 序列帧 | 确定性（同输入必同输出）、可参数化、可拉伸、批量 | 只有 CSS 能画的东西，无艺术细节 |
| **AI 文生图** | 立绘、复杂图标、写实纹理 | 艺术感、细节、风格化 | 不可控尺寸/边框/确定性，难批量对齐 |

## 决策树（怎么选）

```
你的资产需要什么？
│
├─ 运行时动态 / 需要实时响应玩家操作？
│     └─ YES → TA/引擎（粒子系统、shader、后处理）
│
├─ 静态资产，但需要艺术细节（质感/写实/复杂造型/风格化）？
│     └─ YES → AI 文生图（立绘、复杂图标、场景背景、纹理）
│
├─ 静态资产，几何/纯色/渐变/可拉伸，且需要：
│     □ 精确尺寸与边框    □ 参数化变体    □ 批量生成    □ 像素级确定
│     └─ 命中任一 → MyAssets（按钮/面板/贴图/UI 序列帧）
│
└─ 不确定？看下面的资产清单
```

## 各类资产推荐路径

### ① 该技术美术/引擎做的（MyAssets 不做）

| 资产 | 原因 |
|---|---|
| 粒子爆发（火/烟/爆炸/雨雪） | 运行时计算，需实时调参 |
| shader 后处理（Bloom/扭曲/流光/溶解） | 动态程序化效果，TA 编写（文档 2.1 节） |
| 物理模拟、布料、流体 | 运行时 |
| 需要与场景/光照互动的特效 | 预渲染无法满足 |

### ② 该 MyAssets 做的（CSS 确定性渲染强项）

| 资产 | 说明 |
|---|---|
| **九宫格 UI**：按钮/面板/进度条 | 自动测边框、可拉伸、状态变体批量出 |
| **程序化贴图**：渐变/光晕/辉光/遮罩/流光 | CSS 渐变+滤镜天生擅长，一行 CSS 一张贴图 |
| **静态界面整屏**：主菜单/结算屏/商店 | AI 写布局，整屏确定性出图 |
| **UI 简单动画序列帧**：呼吸发光/点击反馈/飘字 | 引擎播放序列帧还原 |
| 需要确定性的装饰元素 | 像素级一致，可验证 |

### ③ 理论上 MyAssets 能做、但 AI 文生图效果更好的

| 资产 | 为什么文生图更好 |
|---|---|
| 角色立绘/原画 | 艺术细节和风格，CSS 无法企及 |
| 复杂道具/装备/武器图标 | 需要质感、光影、造型复杂度 |
| 场景背景/氛围图 | 写实或艺术风格 |
| 写实纹理（木纹/金属/布料） | 文生图的噪声和细节自然 |
| 需要"看起来像画师画的"一切 | 艺术性是文生图主场 |

> **边界提醒**：MyAssets 能"画出"简单几何/渐变/光晕，但**画不出艺术感**。判断标准很简单——这个资产如果画成纯几何图形还能用，就归 MyAssets；如果必须靠细节和风格打动人，归文生图。

## 组合使用（真实项目怎么用）

一个卡牌游戏里三种方式通常混用：

```
卡牌UI底框（九宫格，可拉伸）    ← MyAssets
卡牌立绘（艺术细节）            ← AI 文生图
抽卡金光（粒子+后处理）         ← TA/引擎
卡牌稀有度光晕贴图（透明PNG）   ← MyAssets（程序化贴图）
```

MyAssets 与文生图天然互补：文生图出"美术层"，MyAssets 出"结构层"（UI 底框、光晕、遮罩），两者叠加就是完整资产。
